
# Campus Service

## Project Goal
A simple JavaScript project demonstrating DevOps
practices, version control, automated testing,
branching and Continuous Integration.

## How to Run Tests
1. Install Node.js.
2. Open the project in VS Code.
3. Open the terminal.
4. Run: npm test

## Tools Used
- VS Code
- Node.js
- Git
- TortoiseGit
- GitHub
- GitHub Actions
